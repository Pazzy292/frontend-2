# Ferries Greece React Replica

A React/Vite implementation inspired by the layout and booking flow of ferries-greece.com.

Important: This project deliberately uses original placeholder text, CSS illustrations, and demo data. It does not copy protected images, logos, review text, or proprietary assets from the referenced website.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
